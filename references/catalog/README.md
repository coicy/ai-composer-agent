## Coverage

See COVERAGE.md, coverage.json, TARGETS.md and targets.json. Feature dimensions are independent; no verified genre, mode, swing or form claims are inferred from MIDI alone.

## Usage

1. Hear the originals in an external General MIDI player.
2. In ai-composer-agent use Import MIDI; verify note content and track division, not instrument/tempo fidelity.
3. Feed feature summaries to an external LLM Agent rather than pasting entire copyrighted music into context.
4. Preserve source and license information from manifest.json.

These original MIDI bytes have NOT been quantized, normalized, edited or re-exported.
