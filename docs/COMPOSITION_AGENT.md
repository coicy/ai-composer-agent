# 音乐创作 Agent 协议

## AI 生成模型边界（D-005，2026-10-22）
**音乐创作由大语言模型（LLM）完成，不引入专用音乐生成模型及其权重。** 可调用确定性音乐理论分析、和声约束校验、候选评估和已有离线规则演示辅助工作，但不得替代 LLM。优化方向是改善 LLM 音乐上下文、分阶段规划、结构化 MIDI 输出、外部验证和人工听评，而非引入 MIDI-GPT 类模型。


## 任务类型
compose_melody（从零创作）、continue_phrase（续写）、variation（变奏）、reharmonize（重配和声）、create_bass（低音）、create_accompaniment（伴奏）、evaluate_candidate（结构评估）。

## 流程
1. 读取创作目标：长度、拍号、调性、节奏、风格、情绪、配器；未规定事项作为可修改提议而非强制事实。
2. 读取当前范围/锁定/已有主题与音乐上下文，确认可写区间。
3. 规划曲式、短动机、节奏与旋律弧线；可先旋律、先和声或联合生成，禁止固定流水线假设。
4. 提出真实音符及操作集，至少具有稳定 noteId、pitch、startTick、durationTicks、velocity。
5. 使用确定性校验结构、时值、音域、锁和权限；无效结果重新生成或返回错误。
6. 返回不同候选，不直接应用；预览并征求用户确认。
7. 接受人工作出的变化，基于新 revision 局部修订并尊重未授权范围。

## 质量维度
音符合法性、节奏/结构一致性、动机重复与发展、和声适配、可演奏音域及声部关系分别评价。平行五度等风格相关现象不作为跨风格硬性错误。音乐的情感、原创性及审美质量需要人工试听，模型不能自行认证。

## 防止伪作曲
只输出文本、和弦符号、提示词或波形均不能算完成 compose_melody；必须写出可编辑 MIDI 音符。独立候选不能只是相同音符换轨名。
