# 产品裁决与开放问题

## Accepted（用户已明确）
- D-001：产品为浏览器端轻量级自主作曲与辅助编曲 Agent。
- D-002：Agent 能从零写出真实旋律音符，并可续写/配器。
- D-003：用户必须直接编辑 Agent 创作结果。
- D-004：以钢琴卷帘为主编辑模式，**不使用五线谱**。

- P-002：模型修改前需预览与人工确认，保护锁定范围。
- P-003：MVP 长度 4–16 小节，至少两个候选。
- P-004：TypeScript + React + Canvas，Tone.js 与 @tonejs/midi，服务器可选。
- P-005：采用 monorepo packages/apps 分层。
- P-006：480 PPQ 作为内部初始候选。
