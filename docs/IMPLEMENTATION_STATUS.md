# 实现状态

MVP 原型现具备 pnpm workspace、React/Vite、钢琴卷帘基础单轨编辑/多轨切换、Web Audio 简易试听、基础 MIDI 文件交换、revision/轨道及音符锁检查、内存撤销重做。

新增**确定性程序化旋律候选**：固定 C 大调、4/4、每小节 8 个八分音符、1–16 小节、steps/leaps/motif 三种生成策略。使用 Seed 产生可复现候选；预览以独立操作集形成，必须用户确认后才提交；锁定音符和跨选区边界的既有音符拒绝替换。此能力**不是 LLM 作曲 Agent**，没有自然语言理解、旋律质量保证、和声、结构评估或配器能力。

仍待：Agent 模型接入、自由音阶/拍号、生成更复杂节奏、多轨混音与音色、持久化工程、完善版本并发及端到端编辑测试。CI 以对应提交实际结果为准。
