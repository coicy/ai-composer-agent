# 钢琴卷帘交互规范

## 当前实现（原型）
- 以钢琴卷帘为唯一主音符编辑界面；可切换当前 MIDI 轨道。
- **编辑音符**工具：双击空白网格插入音符；拖动音符主体调整起点和音高；拖动音符右端调整时值；可删除、撤销、重做。
- **框选音符**工具：在当前轨道钢琴卷帘中拖拽二维矩形，选中与矩形相交的真实音符；以稳定 Note ID 标识选区，选中音符高亮。
- Agent 模式：`轨道末尾续写`、`重写指定小节`、`仅重写框选音符`。
- 框选重写以所选音符的最早开始 tick / 最晚结束 tick 为目标范围，**删除操作仅作用于所选 Note ID**；不选中的同刻和弦音或其他声部保持不变。
- 候选用蓝色 ghost 音符显示新增、红色显示待删除。必须用户确认后由 music-core 原子提交；锁、范围、revision 由确定性代码校验。
- 鼠标框选和人工编辑目前互斥，使用工具按钮切换；选区只包含当前轨道。
- AI 每次限 4 个 4/4 小节时长、最多 64 个选中音符；固定 4/4 tick 映射（属于当前实现限制，非最终产品规则）。

## 计划中的能力，尚未实现
- 完整 0–127 自由滚动音域与无极缩放、力度面板、键盘快捷键、Shift 多选、复制粘贴、多个声部并行拖动、框选跨轨道。
- 更丰富的播放光标、乐器音色与 Tempo/Meter Map。
- “保留原有节奏仅改变音高”等指令的结构化约束验证，不能只依赖模型遵循自然语言。
- 自适应移动端、触屏、无鼠标/键盘无障碍。

## 工程约束
鼠标坐标只用于计算选区，不直接写音乐数据。二维命中检测与选区时间计算位于 `packages/piano-roll/src/selection`。候选不等于实际音符，用户批准前不得改变持久工程。版本过期必须重新生成候选。详见 [PIANO_ROLL_SELECTION.md](PIANO_ROLL_SELECTION.md) 和 [SCOPED_REWRITE.md](SCOPED_REWRITE.md)。

## 编辑约束（已实现于当前原型）
- 框选音符后，可选择“只改音高”，对 Agent 生成的新旋律进行确定性节奏保持验证，最终只更新被选中音符的 pitch。
- 工具栏可对框选音符执行 +12/-12 半音候选移调；不调用模型，确认后统一提交与撤销。
- 新增音符使用蓝色 ghost，删除使用红色，音高更新使用高亮并在新音高位置生成预览；更新计数显示在候选摘要。
- 此能力仅验证 MIDI 数据结构约束，不承诺生成曲子的审美质量。

## MIDI 全音域、缩放与人工批量操作（已接入原型）
- 钢琴卷帘支持 MIDI 0–127 纵向滚动，水平缩放 50/100/150/200%，缩放不修改工程 Tick。
- 框选多个音符后切回编辑工具，可以一起拖动；一次拖拽产生单个原子 ChangeSet/撤销项。
- 当前音符可数字编辑 Velocity (1–127)，有多音符选区时批量修改已选音符的力度。
- 对无效音高/时间、锁定音符的批量操作必须拒绝，不得部分写入。
- 现阶段网格是 DOM + CSS 原型，不应误称为高性能 Canvas 引擎；详情见 [PIANO_ROLL_VIEWPORT.md](PIANO_ROLL_VIEWPORT.md)。

## 多方案随机种子比较（已实现原型）
- 编配面板提供整数 Seed 0–4294967295、2–4 候选规模，并允许离线确定性多方案或远程模型多方案生成。
- 每个方案显示 Seed、音符数量、结构提醒和规划偏离数量；切换方案复用已存在的逐轨覆盖预览及试听。
- 可为和声、低音、伴奏分别选择不同候选，组合后须重新通过完整验证才可确认原子新增三轨。
- 同种子**离线模式**可在版本固定时复现；**远程模型模式**仅作为变化引导，不承诺精确复现。见 docs/ARRANGEMENT_VARIANTS.md。
