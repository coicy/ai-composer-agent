# 钢琴卷帘交互规范

主布局：上方 Transport/速度拍号；左侧轨道列表；中央可缩放 Piano Roll；下方 Velocity；右侧可折叠 Agent 会话与变更预览。聊天框不是主要工作区。

Piano Roll：纵向 0..127 音高，横向 tick 和小节/拍网格；拖动音符主体修改音高与开始时间，拖边修改时值；双击或绘制创建音符；点击删除工具或按 Delete 删除；Shift 多选、框选、复制粘贴、缩放与滚动。可切换吸附粒度，默认保留未量化精度（行为待 PoC 确认）。编辑操作必须经过命令执行器。

用户可选择轨道、音符 ID 或 tick 范围作为 Agent 的 Scope；可以锁定轨道/音符。Agent 建议以半透明 ghost notes 和变更摘要预览，显示新增、变更、删除项；用户明确确认才提交。应用后支持撤销/重做。预览期间用户继续编辑导致版本变化，禁用旧预览提交并显示冲突。

无鼠标和触屏支持属于后续可访问性与输入方案细化，不能在 MVP 验收前虚称已完成。
