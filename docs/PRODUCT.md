# 产品需求（规划版 v0.1）
定位：轻量级浏览器 AI MIDI 作曲协作工具，不是完整 DAW，也不是不可编辑的音频生成器。

## AI 创作引擎（正式裁决 D-005）
- 音乐创作、续写、编曲和修改的 AI 生成引擎为**大语言模型（LLM）**，输出真实可编辑 MIDI 音符。
- **不引入专用音乐生成模型、其预训练权重或服务**（例如 MIDI-GPT），不得作为后续任务或实验路线。
- 可使用非 AI 的音乐理论算法、规则校验、music21/MusPy 等分析指标工具、MIDI I/O、音源合成器及已有离线规则演示；不能把它们冒充 LLM 编曲能力。
- Music Core 授权范围、硬约束、预览批准、版本控制与撤销机制保持不变。

## 核心用户旅程
用户描述调性/节拍/长度/情绪/风格 → Agent 原创旋律候选 → Piano Roll 试听和逐音编辑 → 选择范围要求续写、模进、变奏、和声、低音 → 预览候选 diff → 确认应用 → 保存或导出 MIDI。

## MVP 必须
1. 从零生成 4–16 小节旋律，音高、起点、时值、力度完整。
2. 两种候选可比较；没有编辑器也能通过固定输入复现基本结构验证（审美不做自动保证）。
3. 钢琴卷帘：创建/选择/移动/改变长度/删除音符，吸附、缩放、撤销；多轨切换。
4. 播放、暂停、定位、静音、独奏，基础音色；与 tick 同步。
5. 人工改动后 Agent 续写、局部重写、变奏、基本和声/低音与简单伴奏。
6. 锁定音符/轨道、仅修改授权选区、候选预览、确认/取消及冲突处理。
7. 工程 JSON 保存/加载；Standard MIDI File 导入/导出。

## 非 MVP
五线谱、VST、混音母带、音频转 MIDI、录音、实时多人协作、DAW 完整兼容、生成声学波形。

成功标准不仅是生成音符：人工修改可保留，Agent 不能越权覆盖，MIDI 能在其他软件编辑，播放内容与工程一致。
